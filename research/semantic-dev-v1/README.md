## 题集范围

[检索题草稿](retrieval-questions.spec.json)含18个概念，每个概念一条中文和一条英文查询，共36条，不是36个独立概念。[问答题草稿](answer-questions.spec.json)为其中10道中文有出处题及2道指定虚构DOI缺失题。后者只验证指定来源身份，不代表一般领域无答案覆盖。

题目、参考要点与来源范围由助手整理。构建工具核对冻结库、全文摘要、原文锚点及字符区间，保留`source_id`以支持教材；这些技术检查不等于领域人员审定。

## 检索观察

中文指定来源Hit@5从BM25的7/18，提高到E5的12/18；增加可追溯通用术语后，向量检索为15/18，混合检索为16/18。英文向量检索为18/18，混合检索为17/18，因此没有一种配置在所有查询上全面更好。

评价先取得候选片段，再对来源去重并统计前5个来源；来源被召回不表示生成实际采用的片段包含全部答案。登记参考也没有穷举所有正确来源。开发数据参与了术语补充诊断，不作独立测试或答案正确率结论。

## 回答运行

[三组基线摘要](answer-baseline-summary.json)保留36份原始运行的状态和覆盖结果，未启用术语补充。启用术语补充后，应用配置的[12题单组复核摘要](answer-production-before-guard-summary.json)另行保存：9条生成、3条证据不足，无运行错误。此轮使用v6提示且尚未启用复述检查，不代表当前v8提示的完整验收。两类运行的模型相同，检索配置不同，不混算成独立样本。

基线已暴露误拒答、复述问题以及回答不完整等限制。引用编号由程序校验与渲染，不能证明生物事实得到支持。准确性、无支持断言及完整性尚无事实质量评分结果，不将软件测试或拒答状态转换成学术成绩。

## 复述检查与已知失败

单组复核的SEM-18-ZH询问人类过氧化物酶体膜上的ABCD家族成员。引用原文已明确列出ABCD1、ABCD2和ABCD3，但v6输出只重复问题。增加`citation-and-exact-echo-v1`检查：去除引用编号、标点并统一大小写后，若生成内容与问题完全相同，请求一次纠正；仍未通过则明确回退为原文摘录，不显示为生成成功。

保留同一题的三次定向回归，分别登记提示版本，不混合统计：

| 提示与检查 | 实际输出状态 | 诊断 |
| --- | --- | --- |
| [v6加复述检查](echo-guard-v6-summary.json) | provider_fallback | 两次复述均被拒绝，回退为原文 |
| [v7修正结构化纠错契约](echo-guard-v7-summary.json) | generated | 改为笼统陈述，仍遗漏成员名称 |
| [v8要求直接提供具体信息](echo-guard-v8-summary.json) | generated | 仍未列出成员，问题未完全解决 |

v8的实际回答是“人类过氧化物酶体膜上存在ABCD家族转运蛋白 [3]”。当前检查只识别逐字复述，不能识别改写后的空泛回答、全部信息遗漏或生物学错误。这是小模型生成能力的已知限制；来源命中和引用区间覆盖均不能替代完整性评价。v8只跑了这一题，尚未完成同配置12题重跑。
