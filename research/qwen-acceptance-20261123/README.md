# Qwen3.5-4B 冻结问答对照

语料使用 134 份资料、8,083 条向量的基础冻结库。12 道中文题中有 10 道登记教材原文，2 道验证指定 DOI 在该库缺失时的处理。问题依据同库教材整理，部分主题与开发题可能重叠。出答卷前登记题集、语料和代码摘要。

- [冻结题集](dataset.json)保存题目、参考要点、字符区间和原文摘要。
- [生成前冻结协议](FREEZE_MANIFEST.json)保存三组计划与生成模型摘要。
- [裁判运行登记](JUDGE_RUNTIME.json)保存实际安装权重的摘要，模型名称与生成前约定一致。
- [实验汇总](summary.json)保存逐题评价分类、证据覆盖、耗时和分组分母。
- [首评一致性核查](judge-consistency.json)登记空拒答误评分、无实际引用的异常判定及定向复评。

无 RAG、基础 RAG 与优化 RAG 各运行 12 题。两类 RAG 均采用 K=5，基础组使用向量检索，优化组启用混合检索、英文查询转换和一层相邻扩展。检索单项的 BM25、E5 和单路混合对照另行运行，均关闭问题级英文转换。

生成使用本地 Ollama 的 Qwen3.5-4B，评分使用同机 Gemma 3 4B。组名从裁判输入中隐藏，裁判依据参考要点、原文和实际证据进行评分。首评有错误，相关质量指标用于诊断。正文与限制见[论文实验章节](../../docs/论文实验章节草稿.md)。完整答卷、提示、原始裁判响应与运行报告留存在本机实验目录。
