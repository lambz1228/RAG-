# 固定双路版本后的新题三组验证

方法、结果与局限见[三组验证报告](../../docs/双路查询新题三组验证_20261116.md)。本轮题目在产生答卷前冻结，运行后没有按成绩调参；题目与要点由助手编制、来源于现有语料，非外部权威基准。

- `dataset.json`：20道有出处题、2道来源缺失、2道指定教材未给出细节的题，含标准原文区间及摘要。
- `FREEZE_MANIFEST.json`：运行前时间、数据与96个实施文件摘要、配置差异及重复裁判规则。
- `normalized-summary.json`：首次评价按三种题型归一化汇总，失败单列。
- `judge-*`：三组首次评分协议、原始汇总和逐题判定。
- `repeat-judge-*`、`repeat-selection-*`：每组4份的定向重复裁判及选样依据，不覆盖首次结果。
- `retrieval-diagnostics.json`：候选标准片段排名及实际上下文覆盖。
- `repeatability.json`：重复裁判的一致数与逐条分歧。
- `逐题首次评价.md`：三组72条首次结果、评分及裁判依据。

源码ZIP、完整生成答卷、匿名裁判输入、71份首次响应及12份重复响应位于本机`output/unseen-dual-v1/`。ZIP是源码和非敏感配置快照，不含真实环境文件、密钥、权重或资料库。

首次满分数为无RAG22/23（另1次生成失败）、原混合12/24、双路19/24；有出处题分别为18/19、8/20、15/20。两类不可答题三组均处理恰当。无支持断言和引用支持分类在重复子集中各有一次分歧，不据此声称普遍降低幻觉。
