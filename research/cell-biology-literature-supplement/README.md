## 导入 BioKB

安装项目依赖后，从仓库根目录运行以下命令。示例将资料存入独立目录。

```bash
python -m biokb --data-dir data/literature-supplement import research/cell-biology-literature-supplement/records
python -m biokb --data-dir data/literature-supplement stats
python -m biokb --data-dir data/literature-supplement search "溶酶体膜损伤" --strategy bm25
```

`records/` 每个 JSON 对应一篇文献。笔记使用 `knowledge_note`，纯题录使用 `reference_stub`。本批资料作为后续扩充来源，既有冻结语料和评测继续使用各自的版本清单。
