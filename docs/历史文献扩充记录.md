# BioKB 2021—2024 年开放全文扩充记录

日期：2026-11-05。目标：在[前一批开放全文](文献扩充记录.md)偏向 2026 年的基础上，为科研文献与证据知识库补充较早年份的可追溯全文。本记录只对应 `data/research_corpus/historical_20261105/` 与独立的 `data/biokb-v23-historical-20261105/`。

## 获取、许可与身份核验

本次按 12 个细胞器及细胞过程主题、2021—2024 四个年份建立 48 个检索组合。Europe PMC REST 搜索当时持续返回 503，NCBI ESearch 间歇返回 500，OpenAlex 匿名检索返回 429。因此网页搜索只用于发现候选 PMCID，452 个去重候选及原查询保存在 `seed_candidates.json`；没有把网页搜索片段当作论文元数据或正文。

程序逐篇通过 [Europe PMC 官方 REST 全文接口](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC8449344/fullTextXML) 下载 XML，核对文内 PMID、PMCID、DOI、发表年份、标题、摘要、主题词、正文长度及单一明确的许可链接。33 篇入库文献的 XML 都标有 CC BY 4.0。[Europe PMC 版权说明](https://dev.europepmc.org/Copyright)允许使用其指定的 REST 等服务自动获取可重用子集，同时要求逐篇遵守实际许可；本批保留原始 XML 与许可字段，源码包不分发全文。

另用 [PubMed EFetch](https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi) 和 [PMC ID Converter](https://pmc.ncbi.nlm.nih.gov/tools/idconv/api/v1/articles/) 交叉核对 33 篇的 PMID、PMCID、DOI，结果均一致。`pubmed_metadata.xml` 是原始快照，`pubmed_verification.json` 和 `id_conversion_verification.json` 保存查询结果；`verify_pubmed_snapshot.py` 再从原始 XML 重算快照字段，`pubmed_snapshot_audit.json` 显示 33/33 一致。解析只取论文自身的 `PubmedData/ArticleIdList`，不会把参考文献的 ID 误认作本文标识。

PubMed 文献类型中 16 篇带 `Review`。快照未出现撤稿或关注声明标记；其中 `PMC8591368` 与 `PMC10443367` 含 `ErratumIn` 更正关联，`PMC8496184` 与 `PMC8752127` 含 `CommentIn` 评论关联。它们需要进一步读取关联文献，当前自动检查不构成完整撤稿、更正链核验。

## 系统验收与使用

在 SQLite 临时副本上完成 API 验收：论文目录返回 206 篇、74 篇有全文、0 项身份冲突；33 篇新增文献逐篇可用 PMCID 唯一定位；2021 年与 2024 年各一篇题名 BM25 查询能召回目标。结果见 `api_verification.json`。题名检索只是功能冒烟检查，不是独立检索质量或问答正确率。`doctor_verification.json` 在临时副本上确认索引指纹兼容；它不调用模型，也不证明在线模型连通性。

主线 141 项自动化测试通过，新增和修改的主线脚本及测试 Ruff 通过。浏览器在临时副本完成 10 项工作台交互检查，页面和控制台错误均为 0；报告和截图在 `output/historical_20261105_browser/`。正式 v23 数据库在这些测试前后 SHA-256 不变。旧的三份数据库及 v22 SHA-256 与上一批记录一致。

本批次交付时，`start-expanded.bat` 曾指向 v23；当前入口已指向后续 v26。复现本批次时显式使用下面的命令，不更改 `.env` 或旧启动入口：

```powershell
.\.venv\Scripts\python.exe -m biokb --data-dir data/biokb-v23-historical-20261105 serve
```

复核批次时依次执行：

```powershell
.\.venv\Scripts\python.exe -m scripts.verify_pubmed_snapshot --batch data/research_corpus/historical_20261105
.\.venv\Scripts\python.exe -m scripts.verify_expanded_index --batch data/research_corpus/historical_20261105 --target data/biokb-v23-historical-20261105
.\.venv\Scripts\python.exe -m scripts.verify_expanded_api --batch data/research_corpus/historical_20261105 --target data/biokb-v23-historical-20261105
.\.venv\Scripts\python.exe scripts/verify_workspace.py --output output/historical_20261105_browser --snapshot-data data/biokb-v23-historical-20261105
```

原始 XML、筛选副本、数据库和模型凭据均不进入源码包。迁移到其他机器时，需单独迁移获许可的文献与索引，并保留来源和署名信息。

## 科研结论边界与后续

33 篇的数据库质量状态仍为 `unreviewed`。当前完成的是可追溯的数据扩充和工程功能验收；尚缺领域专家对方法、结论、主题相关性的复核，两个更正关联的全文审读，完整撤稿/更正关系链，以及独立证据片段标准题、无答案题和冻结新索引后的检索问答评测。旧 69 道模型生成题不算本次独立科研正确率。15 个空缺组合应作为下一批定向采集目标；再次采集必须新建批次与独立索引，保留本批报告不变。
