## 旧题库v2历史建议（非老师任务书门槛）

旧 v1 的“100题”总数与保留已有题后的最低分类配额不一致。若保留现有 82 题，建议形成 **110题**：方法条件30、机制/结论25、跨论文比较20、无答案20、版本/时效15。当前缺14道跨论文比较和14道版本题。不得凭空填满缺口；须有对应论文、版本与原文证据后再出题。

老师没有规定上述题量或固定双人复核比例。可以根据实际范围安排人工复核和抽查，人员与评分保持待真实填写。任何配额或题目变更产生新题集版本，不追改 v1 冻结记录。

## 检索指标

同语料、分块、问题、候选窗口下比较 BM25、向量、RRF 混合和重排序。保存 Hit@K、Recall@K、AllHit@K、MRR@K、Precision@K、nDCG@K、延迟、逐题排名、语料摘要、索引版本与模型指纹。片段候选去重得到文档排名，最多50个候选，不能解释成全库穷尽排名。

文档命中不代表选中回答所需片段。论文级归并指标通过 `derive_paper_metrics.py` 从冻结排名复算，两种口径分开报告。

## 固定配置的问答对照

```bash
python scripts/run_answer_experiment.py --database <冻结库/knowledge.sqlite3> --dataset <题库目录> --output output/answer-run-01
```

默认按 `taskbook` 配置只读备份源库，运行无检索、基础向量RAG、混合检索加相邻扩展三组；不要求重排序服务。`--profile core`提供五组进一步消融；`--profile rerank`才要求真实重排序并运行七组扩展。每题内随机组顺序；保存完整上下文、实际引用、提示版本与公开配置，不将标准答案发送给模型。

输出打乱顺序且隐藏组名的 `盲评表.csv`，对应组名和参考要点放在单独的协调者密钥。表中保留事实正确性、证据支持、完整性、拒答恰当性、无支持断言数等字段，由真实人员评分。回答措辞和引用形式可能透露方法，因此这是组名隐藏，不保证完全消除评审偏倚。

证据区间覆盖率只表示已标区间被上下文或实际引用覆盖的比例，不称为独立原子证据召回。模型失败、合法拒答、部分支持和原文回退分开保留。

## 离线流程验证

`reproduce_demo.py` 产生的开发题可配合 `--offline` 运行三个哈希 / 摘录对照。离线模式不会调用模型，结果始终标为流程演示，学术正确率为 `null`。任务书三组模型实验需要真实 embedding 与生成；重排序仅是可选实验；错误配置或库指纹不符会停止。

任务书原文与验收映射见[任务书对照](任务书对照与验收.md)，实际操作与评分口径见[真实模型实验操作](真实模型实验操作.md)。
