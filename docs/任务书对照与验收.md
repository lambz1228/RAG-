# 老师任务书与实现对照

## 任务书原文

命题内容和要求：

> 采集并整理生物领域文献资料，构建向量化的领域知识库；基于检索增强生成（RAG）架构，结合大语言模型实现知识的精准检索与问答生成；评估系统在回答准确性、幻觉抑制等方面的表现并持续优化。

专业基础条件：

> 掌握Python与常用大模型调用接口，熟悉向量检索、Embedding与RAG基本流程，了解生物领域基础知识。

预期成果：

> 完成一套面向生物领域的智能知识库问答系统原型，并形成一篇验证系统有效性的毕业论文。

以上由用户提供的老师任务书截图转录。任务书没有规定100题、110题、90%正确率、特定评审者资历或必须提出新算法。这些不能额外作为老师的验收条件。

## 对应实现与证据

| 要求 | 对应实现 | 如何核验 |
| --- | --- | --- |
| 文献采集与整理 | 官方六主题发现、来源标识与许可检查、明确纳入排除记录 | 查看来源响应、`SELECTION.json`、冻结清单 |
| 向量化领域知识库 | 真实Embedding与独立语义索引，模型变更指纹保护 | 核对模型文件摘要、向量维度、数量与库摘要 |
| 大语言模型问答 | 原文召回、上下文选择、结构化生成与引用定位 | 保存真实响应模式、完整证据及失败回退 |
| 精准检索评价 | 同一冻结库上的BM25、真实向量与混合检索 | 开发题逐题排名与Hit、Recall、MRR |
| 准确性与幻觉抑制评价 | 无RAG / 基础RAG / 优化RAG对照，真实人员评分汇总 | 盲评CSV、答卷绑定、正确性/无支持断言/拒答指标 |
| 持续优化 | 开发失败归因、配置消融、保留旧结果与新版本 | 对照配置、失败类别与新版本回归 |
| 系统原型 | 知识库、采集、检索、问答、评价与历史 | 本地启动、API与浏览器回归 |
| 验证有效性的论文 | 任务、方法、系统、实验、局限与结论 | 实测结果和真实评分支撑论断；不编造结论 |

## 必须区分的状态

“真实模型运行完成”证明模型链路实际执行。“检索命中”证明标准文档被召回。“引用编号通过”证明编号与片段对应。只有经过适当复核的参考答案和真实评分，才能用于报告本任务集上的回答准确性与无支持断言比例。

机器草稿、开发题和无答案候选都需标明来源。当前开发集不具备独立测试集地位，小规模、点名论文的问题可能明显高估泛化效果。

用户可以结合原文完成初次人工复核，再根据导师意见安排抽查或第二位评审。软件不代填“人工”字段，也不要求任务书未规定的专家门槛。
