## 4. 系统架构

```
src/biokb/
├── app.py / cli.py      入口（app.py 或 python -m biokb serve）
├── config.py            Settings.from_env()，系统变量仅存引用名
├── container.py         build_services()：应用工厂 + 依赖注入，导入时不建库/扫描/调模型
├── storage.py           SQLite 仓储：documents/chunks/embeddings/query_runs/jobs
│                        + conversations/conversation_messages（会话问答）
├── retrieval.py         BM25 / dense / hybrid / hybrid_rerank 检索
├── reranking.py         重排序适配
├── rag.py               RAGService.ask()：检索→筛选→生成→引用校验；支持会话历史
├── providers.py         模型适配（embedding/rerank/LLM）；PROMPT_VERSION 指纹
├── evaluation.py        检索评估（Recall@k 等）
├── jobs.py              单实例任务队列（SQLite 持久化）
├── quality.py           文献质量/许可元数据
└── web/
    ├── app.py           Flask 路由（/api/*），未配置访问令牌时仅本机
    ├── static/          前端（原生 ES 模块：main/research/documents/ui/i18n/messages）
    │                    app.css 为视觉层，2026-11 全面改版 + 会话聊天气泡
    └── templates/index.html
```

职责边界：配置 / 数据访问 / 文献处理 / 检索 / 模型适配 / 问答 / Web 路由分层隔离；新增主线测试放 `tests/biokb/`。

## 7. 常见问题

- **测试挂了**：先跑 `pytest -q`；历史测试结果单独记录，不与主线通过率混合。
- **正式库被改动**：任何脚本写库前核对 SHA-256（第 2 节），迁移必须写新库。
- **问答结果与记忆不符**：带历史的对话 `prompt_version` 有 `-conversation` 后缀，属预期；评估结论只认单轮、冻结题集、人工评分。
- **服务日志**：`output/serve_log_20261114.txt`（按日期滚动）。
- **单实例限制**：任务状态持久化仅支持单实例单进程，勿双开 `app.py`。
