# BioKB 开放全文扩充与独立入库记录

日期：2026-11-05。对象：面向科研的生物文献与证据知识库。此记录对应一次新增数据批次，不追写既有科研质量验收结果，也不代替领域专家复核。

## 来源与收录条件

本批通过 [Europe PMC 官方 REST 搜索接口](https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=OPEN_ACCESS%3Ay&format=json&pageSize=1) 查询 12 个细胞器及细胞过程主题，限定 2021—2026 年、PubMed 来源、英文、有摘要及官方开放获取标记。对候选逐篇下载官方全文 XML，例如 [PMC13718449 的全文 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC13718449/fullTextXML)。只有全文给出唯一、明确的 CC BY 3.0/4.0 或 CC0 许可链接，且 XML 中 PMID、PMCID、DOI 与官方记录一致、正文可提取时才进入采集批次。本次最终入库的 38 篇均为 CC BY 4.0。

开放获取标记只用于发现候选；许可判定基于每篇全文的许可声明。采集脚本排除标题或文献类型显示为撤稿、更正或关注声明的记录，但尚未建立完整的撤稿、更正关系链，相关状态仍需进一步核对。

## 使用与复现

本节记录 v22 的历史批次。`start-expanded.bat` 当前指向后续 v26 库，复现 v22 应使用下面的显式 `--data-dir` 命令启动。

在本机启动 v22：

```powershell
.\.venv\Scripts\python.exe -m biokb --data-dir data/biokb-v22-expanded-20261105 serve
```

检查 v22 配置和索引时使用：

```powershell
.\.venv\Scripts\python.exe -m biokb --data-dir data/biokb-v22-expanded-20261105 doctor
```

原有 `.env` 和 `start.bat` 的数据目录设置没有更改。源码包不含 XML、数据库、原文或凭据；换机使用扩充版时需单独迁移获许可的批次和新库，并保留署名与来源信息。

本次依次使用 `scripts.expand_open_corpus`、`scripts.curate_open_corpus`、`biokb create-revision`、`scripts.import_expanded_corpus`、`scripts.verify_expanded_index`。采集分三轮：先对 `mitophagy`、`er_stress` 各取 1 篇新论文；再对 12 个主题分别尝试 1 篇既有摘要补全文和 2 篇新论文；最后对 `golgi`、`cytoskeleton`、`peroxisome` 定向补采。再次采集应另建批次和索引目录，因为官方检索结果和许可可能变化，不应覆盖本次清单。
