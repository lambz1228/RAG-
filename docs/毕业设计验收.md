## 原型验收

**原型达到单机演示验收要求。** 本机使用 E5 语义索引和 Ollama 上的 Qwen3.5-4B。支持文献发现与导入、BM25／向量／混合检索、限定范围问答、引用定位、会话与导出。

| 验收内容 | 证据与判定 |
| --- | --- |
| Windows 默认编码测试 | 已为 UTF-8 测试资料明确声明编码，`python -m pytest -q` 通过 211 项。Ruff 检查及 78 个文件格式检查通过 |
| 浏览器流程 | 完整工作台、双语界面、文献来源、限定论文范围和回答评价五类回归均通过。涉及后台接口的用例使用受控响应 |
| 官方检索 | Europe PMC 和 PubMed 的在线查询均成功返回 3 条文献记录，本次验证只读取查询结果 |
| 真实运行 | 本机模型已完成中文转英文检索、带出处问答及证据不足处理。历史样例保留了一例带引用回答仍不完整的情况 |
| 冻结语料 | 基础库 134 份资料、8,083 条向量。扩充库 201 条资料、8,150 条向量，其中 28 条纯题录。两套清单共 753 个文件通过摘要校验 |
| 安装与启动 | 在独立 Python 3.12 环境安装 wheel 后验证 CLI。使用独立源码副本验证 `app.py`。两个入口的页面、静态资源和 API 均通过。离线样例完成两篇文献及六条实验流程记录 |

文献来源、模型配置和演示命令分别见[生物知识来源](生物知识来源.md)、[本地模型配置](../config/ollama.env.example)和[开发与部署](开发与部署.md)。Windows 健康检查采用五个等价 HTTP 接口，浏览器报告保留 PowerShell 执行策略限制。

源码入口的离线验收曾读取本机 `.env`，使关闭生成模型的测试组合继承了开启英文转换的设置。验收脚本现在使用无本机配置的临时源码副本，两条启动路径均已复测通过。实际部署继续读取它的运行配置。

## 论文与答辩材料

[论文实验章节草稿](论文实验章节草稿.md)记录试验方法、题集范围与结果。在同一冻结语料上分别比较检索排序和问答效果，报告各组有效答卷分母、错误和失败。

Qwen3.5-4B 在 12 道冻结题上完成三组共 36 次运行，生成错误和摘录回退均为 0。有出处题的实际上下文命中从基础组的 3/10 增至优化组的 7/10。首评的三组原始评分全部保留。空拒答被错误判满分、引用适用性判断错误等情况已登记，正确率和幻觉抑制结论还需校准评价。 [三组试验与核查](../research/qwen-acceptance-20261123/README.md)

答辩演示使用已经核对的基础语料副本。先展示资料数量和向量模型，再检索教材的细胞周期章节。可以用本次对照中的细胞周期题展示中英文查询、证据和引用定位。最后用指定文献缺失情形展示证据不足反馈，并说明该提示当前采用通用表述。离线样例可用于单独复现入库、检索和原文定位。

论文送审需采用学校正式模板并完成导师审阅、要求的检测和答辩材料提交。本文件记录工程和实验核验。
