# 细胞生物学知识库的实现与自动评价

## 1 实验对象和运行配置

BioKB 面向细胞生物学资料的检索与证据问答。系统采用 Python、Flask 和 SQLite，支持文献管理、检索调试、问答、引用定位及结果导出。工作台使用单机单进程部署。

基础库收录 70 篇综述和 64 个 OpenStax Biology 2e 教材小节，共 134 份资料和 8,083 个分块。扩充库另增加 39 份可检索的中文知识笔记及 28 条纯题录，共 201 条资料和 8,150 条 E5 向量。纯题录标为待补充，不参与证据检索。语料纳入、来源和复现步骤见[基础语料记录](../research/cell-biology-expanded-v2/README.md)与[补充文献清单](../research/cell-biology-literature-supplement/README.md)。

基础库采用 800 字符分块、120 字符重叠。多语言 E5 ONNX 使用固定模型修订，输出 384 维向量。文献和查询使用各自的角色前缀，再通过掩码平均池化和 L2 归一化得到向量。生成与英文查询转换均经 Ollama 调用本地 Qwen3.5-4B 四位量化模型。生成使用结构化论断模式，允许程序逐条检查引用编号。配置见[本地模型示例](../config/ollama.env.example)。

## 2 检索开发结果

检索采用 BM25、E5 向量或倒数排名融合。中文问题可保留原表达，同时生成忠实的英文检索表达，两路各自执行混合检索后融合候选。英文转换失败时沿用原查询。问答在上下文预算内去重，按配置纳入相邻片段，并保留原文位置。

既有检索开发题包括 18 个概念，每个概念有一条中文和一条英文查询。在基础语料的中文开发查询中，BM25 的指定来源 Hit@5 为 7/18，E5 为 12/18，E5 加术语补充为 15/18，混合检索加术语补充为 16/18。该轮对照已参与术语补充诊断，统计的是来源召回，问答内容需要依据参考原文另行评分。分组配置及英文检索结果见[检索开发记录](../research/semantic-dev-v1/README.md)。

## 3 本地问答功能核验

在基础库副本上，通过 Ollama 实测中文问题的英文转换、依据教材生成带引用的回答，以及指定教材未给出实验数据时的证据不足反馈。带引用场景记录为部分回答，证据不足场景未使用引用。这两条记录用于核验真实调用和输出状态。耗时及生成状态见[本机验证记录](../output/local-ollama/verification.json)。

带引用的答卷仍可能出现事实表述偏差。一次复测中，模型将化学键单列为 ATP 的组成部分。教材将 ATP 描述为腺嘌呤与核糖形成的腺苷连接三个磷酸基团。正式评分时据原文分别核查事实与引用支持。

## 4 正式对照方案与后续记录

Qwen3.5-4B 的正式对照待开展。先固定语料、索引、代码、模型标识和题集，保存参考要点与证据区间。开发题用于调试，未参与优化的题用于正式对照。指定来源缺失与指定原文未提供细节分别记录。

| 组别 | 配置 |
| --- | --- |
| 无检索 | 使用同一生成模型直接回答 |
| 基础 RAG | 向量召回并使用召回片段生成 |
| 优化 RAG | 混合检索配合双路查询和受控相邻片段扩展 |

两组 RAG 使用相同的有效上下文预算和生成要求。整条链路的结果用于比较两种配置，单独组件的贡献需通过控制变量实验估计。记录 Hit@K、Recall@K、MRR、实际证据区间覆盖以及端到端耗时。运行入口见[真实模型实验操作](真实模型实验操作.md)。

自动裁判选用与被测模型不同的模型。对匿名答卷统一提供参考原文与评分规则，评价正确性、完整性、引用支持、拒答恰当性和无支持断言。生成失败、裁判失败及摘录回退单独计数。无检索组的引用支持不适用。正式结果保留逐题记录与分母，并明确题集范围及模型自动评价的局限。具体流程见[自动评测方案](自动评测方案.md)。
