# 生物知识从哪里来

本课题以细胞生物学为范围，先建立小而可核查的文献库，再逐步扩充。建议从每主题 5—10 篇综述建立知识框架，再为实验条件与机制问题补充原始研究。文献数量不是质量指标。

## 当前接通的来源

[Europe PMC](https://europepmc.org/) 提供官方检索、PubMed 元数据和可取得的 PMC 全文接口。页面支持18个主题，检索式将主题和补充关键词限制在标题与摘要，避免仅在正文偶然提及的文章大量混入；年份与开放获取限制始终保留。请求发送到固定的 `www.ebi.ac.uk` 官方接口，不执行用户输入的任意 URL。

在「文献采集」选择「PubMed (NCBI)」可直连 NCBI E-utilities。检索使用 ESearch，记录读取和入库前的 PMID 复核使用 EFetch。入库保存摘要或仅有题录的记录，并将原始 XML 保存在 `sources/pubmed/`。可通过 `BIOKB_PUBMED_EMAIL` 配置发送给 NCBI 的联系邮箱。开放获取筛选和按许可导入全文的功能在 Europe PMC 选项下提供。[NCBI 接口说明](https://www.ncbi.nlm.nih.gov/sites/books/NBK25499/)

## 入库与来源链

选择论文后重新通过 PMID 获取官方记录。可取得全文时核对 XML 中的 PMID / PMCID；仅在文章许可存在明确的 CC BY 或 CC0 链接时自动提取正文。图片和补充材料不自动下载。没有可用全文或许可不满足规则时只导入摘要，并给出明确状态；标识不一致时停止入库。

原始记录、XML 保存在所选运行目录的 `sources/europepmc/`，文件名含内容摘要。入库 JSON 保留题名、作者、期刊、年份、PMID、PMCID、DOI、来源 URL、资料类型和许可；原始文件归档和规范化正文位置另行保存。全文与摘要不能互换评价口径。

## 中文数据库题录导入

1. 通过有访问权限的中国知网（CNKI）、万方数据、维普或 SinoMed 检索文献并导出题录。选择 EndNote Tagged 文本（字段以 `%0`、`%T` 等标记）或 RIS（字段以 `TY  -`、`TI  -` 等标记）。其他结构的文件可先用文献管理工具转换为上述格式。
2. 打开本项目的「文献采集」→「导入中文文献题录」，选择来源、主题和文件后提交。每批最多100条、1 MB，可使用 UTF-8、带 BOM 的 UTF-16 或 GB18030 文件。
3. 核对新增摘要、题录、重复及失败数。系统按记录分别入库，有摘要的使用摘要作为检索材料，仅题录的标记为待补充。原始导出文件按 SHA-256 归档在运行目录 `sources/<来源>/`，文档元数据保留相应摘要值。

以上四个中文来源通过导出文件入库。数据库内检索和导出在各自平台进行，平台 API 直连尚未启用。SinoMed 的官方帮助说明了题录输出方式。[SinoMed 结果输出帮助](https://analysis.sinomed.ac.cn/help/content/2.4.5.html)

## 可扩充的其他来源
- [NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/)：适合背景知识与教材式概念，逐书核对许可后手动导入可用章节；不批量复制受版权保护的教材。
- [UniProt](https://www.uniprot.org/)：可为蛋白质功能与命名提供人工核对参考，当前没有结构化自动同步模块。
- [Gene Ontology](https://geneontology.org/)：可用于术语与过程分类，当前没有本体推理或自动入库模块。

命令行工具从 OpenStax 官方固定修订取得 Biology 2e 的64个基础小节，逐文件核对摘要，并保留 CC BY-NC-SA 4.0 许可与署名。

扩充版语料包含70篇综述与64个教材小节，按18个主题组织。清单、许可边界、合并及复现步骤见[扩充语料说明](../research/cell-biology-expanded-v2/README.md)。

## 数据规模与科研评价

开发时可以用每主题 2 篇的采集命令验证全流程。正式语料应冻结后再出评测题；保留同一工作的预印本、更正和不同版本关系。自动来源校验、许可证识别与文件哈希不能证明文章结论正确，科研事实与答案支持程度需单独评价。当前采用[自动评测方案](自动评测方案.md)，人工审阅作为可选补充。
