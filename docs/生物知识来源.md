# 生物知识从哪里来

本课题以细胞生物学为范围，先建立小而可核查的文献库，再逐步扩充。建议从每主题 5—10 篇综述建立知识框架，再为实验条件与机制问题补充原始研究。文献数量不是质量指标。

## 当前接通的来源

[Europe PMC](https://europepmc.org/) 提供官方检索、PubMed 元数据和可取得的 PMC 全文接口。页面支持六个主题，检索式将主题和补充关键词限制在标题与摘要，避免仅在正文偶然提及的文章大量混入；年份与开放获取限制始终保留。请求发送到固定的 `www.ebi.ac.uk` 官方接口，不执行用户输入的任意 URL。

| 主题 | 建议补充英文词 | 适合的问题 |
| --- | --- | --- |
| 线粒体与能量代谢 | mitochondria, ATP, oxidative phosphorylation | 能量代谢、膜电位、细胞器互作 |
| 自噬与溶酶体 | autophagy, lysosome, mitophagy | 自噬流、降解途径、选择性自噬 |
| 细胞信号转导 | EGFR, MAPK, mTOR | 通路机制、上游下游、处理条件 |
| 内质网与蛋白质稳态 | endoplasmic reticulum, proteostasis | 蛋白折叠、应激反应、稳态 |
| 细胞周期与凋亡 | cell cycle, apoptosis | 周期调控与程序性细胞死亡 |
| 过氧化物酶体 | peroxisome, PEX | 生物发生、脂质代谢、细胞器定位 |

检索结果需要使用者阅读题名和摘要后选择；自动主题归类不代表领域专家审核。建议记录纳入原因、排除原因与重复版本，不能把“开放获取”当作“与课题相关”。

## 入库与来源链

选择论文后重新通过 PMID 获取官方记录。可取得全文时核对 XML 中的 PMID / PMCID；仅在文章许可存在明确的 CC BY 或 CC0 链接时自动提取正文。图片和补充材料不自动下载。没有可用全文或许可不满足规则时只导入摘要，并给出明确状态；标识不一致时停止入库。

原始记录、XML 保存在所选运行目录的 `sources/europepmc/`，文件名含内容摘要。入库 JSON 保留题名、作者、期刊、年份、PMID、PMCID、DOI、来源 URL、资料类型和许可；原始文件归档和规范化正文位置另行保存。全文与摘要不能互换评价口径。

## 可补充但尚未自动接通的来源

- [NCBI Bookshelf](https://www.ncbi.nlm.nih.gov/books/)：适合背景知识与教材式概念，逐书核对许可后手动导入可用章节；不批量复制受版权保护的教材。
- [UniProt](https://www.uniprot.org/)：可为蛋白质功能与命名提供人工核对参考，当前没有结构化自动同步模块。
- [Gene Ontology](https://geneontology.org/)：可用于术语与过程分类，当前没有本体推理或自动入库模块。

这三项是资料扩充建议，不作为已实现功能。当前自动采集只接通 Europe PMC；上传入口支持使用者已有且有权使用的文献与研究笔记。

## 数据规模与科研评价

开发时可以用每主题 2 篇的采集命令验证全流程。正式语料应冻结后再出评测题；保留同一工作的预印本、更正和不同版本关系。自动来源校验、许可证识别与文件哈希不能证明文章结论正确，科研事实与答案支持程度仍需人工审阅。
