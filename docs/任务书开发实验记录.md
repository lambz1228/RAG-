# 任务书开发实验记录

本轮把老师要求中的文献采集、向量库、大模型问答与效果评价接到实际运行链路。它是小规模开发验证，不能替代独立测试，也没有事实质量评分结论。当前以[自动评测方案](自动评测方案.md)为主，人工评分为可选补充。

## 已完成的真实运行

| 项目 | 本轮记录 |
| --- | --- |
| 语料 | 7份资料，5份正文与2份摘要；纳入、排除及原始响应摘要有记录 |
| 向量 | 446个片段，Qwen3-Embedding-0.6B Q8_0，1024维 |
| 生成 | Qwen2.5-1.5B-Instruct Q4_K_M，经本地llama.cpp调用，CPU运行 |
| 开发题 | 12道草稿，10道带出处、2道指定DOI缺失题，尚未经真实人工复核 |
| 问答 | 两轮各36份记录，无检索、基础RAG、优化候选各12份 |
| 原库保护 | 备份冻结、文件摘要校验，两轮均确认源库未变化 |
| 内容评分 | 历史人工记录0/36，现作为可选补充；该项指标未生成 |

语料并非细胞生物学的全面覆盖，方法与术语跨中文提问和英文原文。仅5篇正文与2篇摘要不足以声称完整领域知识库。实际文件摘要和模型修订见[语料摘要](../research/taskbook-dev-v1/corpus-summary.json)及[模型来源](../research/taskbook-dev-v1/model-provenance.json)。

## 检索对照

10道带出处题、K=5，三种检索的文档Hit@5与Recall@5均为1.0；BM25的MRR@5为0.92，向量与混合为1.0。这只说明小库中的文档被检索到，不能证明答案正确。

最终送入生成的证据区间覆盖均值，基础RAG为0.85，优化候选为0.75，均以10道有出处题计算。增加相邻片段占用上下文预算，可能挤掉参考区间，故本轮没有“优化组全面更好”的结论。区间覆盖也不是语义支持程度。

## 输出协议诊断与改进

第一轮为正文与引用列表由模型直接生成。第二轮改为结构化论断及来源编号，程序校验后渲染；权重、冻结库和题集相同，输出约束与提示版本不同。

| 运行 | 无检索 | 基础RAG | 优化候选 |
| --- | --- | --- | --- |
| 第一轮 | 9份answered、2份partial、1份错误 | 1份generated、11份回退 | 1份generated、11份回退 |
| 第二轮 | 10份answered、2份partial | 9份generated、3份partial | 7份generated、3份partial、2份回退 |

`answered`是无检索输出状态的简称；`generated`表示有引用的生成输出通过程序契约，`partial`表示输出不充分；它们都不是正确性分数。第一轮大部分RAG回退来自引用契约失败；第二轮仍有无效JSON等输出失败，均保留，不用重试覆盖。

结构化模式使两个RAG组总回退由22/24降至2/24，仅能称为本开发题上的输出协议改进。引用展示由程序完成，不能据此得出“事实幻觉降低”的结论。同一题集参与了诊断，两个版本不是独立测试。并发开发活动影响耗时，未报告速度提升。

人工逐条评分前仍能观察到内容限制：DEV-01有答案复述题目而没有给出变化方向；DEV-02无检索输出包含与参考要点不一致的蛋白定位和功能描述，RAG输出也有信息遗漏。以上是开发排查举例，没有转写成虚构人工分数。

两轮机器摘要分别见[第一轮](../research/taskbook-dev-v1/answer-baseline-summary.json)、[第二轮](../research/taskbook-dev-v2/answer-claims-summary.json)。第二轮的[36份待评分答卷](../research/taskbook-dev-v2/review/盲评表.csv)保留真实答案，如自愿开展人工评价，可按[说明](../research/taskbook-dev-v2/README.md)分发；不作为必做项。

## 软件验收与任务书剩余项

本轮本地167项测试通过，Ruff检查与格式检查通过；真实模型实验与这些软件检查分开记录。浏览器验证覆盖上传、检索、问答、工作区、回答质量评价、中英文与移动端；独立环境安装3.1.0 wheel后通过命令入口、静态资源与API检查。

已实现真实评分的上传、答卷与协议摘要绑定、完整性校验、分组汇总和导出。空白或部分评分不生成整组准确率；无检索组的引用支持率不适用。回退和错误单独保留，不能冒充有效生成答卷。

完成论文有效性论证仍需：另建未参与调试的题集并核对其来源与证据，在自动评测路线下补充明确标注的事实质量评价，再依实际结果讨论准确性和无支持断言。人工或专家评分不作为前置条件。任务书没有100题、110题、90%准确率或固定专家门槛；工作量和评价办法可与老师沟通，不能把建议写成既定要求。

复现步骤见[真实模型实验操作](真实模型实验操作.md)，可据实整理的文字见[论文实验章节草稿](论文实验章节草稿.md)。
