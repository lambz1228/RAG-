# BioKB 2021—2024 年缺口文献扩充与作者元数据修复

日期：2026-11-05。本记录接续[历史文献扩充记录](历史文献扩充记录.md)，覆盖 `gapfill_20261105`、`peroxisome_targeted_20261105` 两个独立采集批次，以及 v24、v25、v26 三个独立数据库版本。目标是给上一批尚缺的 15 个主题×年份组合各增加至少一篇可追溯开放全文，并修复本轮发现的作者解析缺陷。原有数据库、XML 和实验结果保留。

## 候选发现与逐篇核对

普通 Europe PMC 主题检索当时返回 503，NCBI ESearch 返回 500。首批使用 [Crossref REST](https://api.crossref.org/works) 按题名和年份发现 DOI，再通过 [PMC ID Converter](https://pmc.ncbi.nlm.nih.gov/tools/idconv/api/v1/articles/) 映射 PMCID。15 组共取得 602 个候选位置、590 个去重 PMCID；60 份接口原始响应、查询 URL 和 SHA-256 保存在 `gapfill_20261105/discovery_snapshots/`。Crossref 和 ID Converter 只负责发现候选与标识映射，**不作为全文、许可或最终发表年份的依据**。

首批填充 14/15 组。剩余的 2024 年 `peroxisome` 组合中，原查询 `peroxisome biogenesis` 的后续候选题名多数是其他生物发生过程；`peroxisome_retry_20261105/` 保存了从冻结清单提取的 14 个未尝试和 5 个网络失败可重试候选，但没有把它们误计为新文献。随后使用更具体的 `query.title=peroxisome` 和题名包含 `peroxisom` 的条件，单独保存 Crossref 与 ID Converter 响应及 SHA-256，获得 46 个可核对 PMCID。这个题名条件只减少初筛量，不代替主题或正文审查。

采集脚本逐篇从 [Europe PMC 官方全文 XML 接口](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC11269463/fullTextXML) 取得 JATS 原文，核对 PMID、PMCID、DOI、官方发表年份、题名和摘要主题、正文长度与唯一明确的 CC BY/CC0 许可链接。两批最终纳入的 15 篇均标有 CC BY 4.0；原始 XML 与转换 JSON、许可及拒收原因保存在各自批次，源码包不分发全文。[Europe PMC 版权说明](https://dev.europepmc.org/Copyright)还要求按论文实际许可使用资料。

两批分别通过 [PubMed EFetch](https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi) 与 PMC ID Converter 对 15 篇的 PMID、PMCID、DOI 交叉核对；原始 `pubmed_metadata.xml`、标识转换响应和重算核验报告均留档。首批 14 篇中 3 篇带 PubMed `Review` 类型。两个批次的快照均无撤稿标记，但首批有 2 条 `ErratumIn`、1 条 `CommentIn`、1 条 `UpdateOf` 关联；补采论文 `PMC11269463` 有 `UpdateOf` 关联，指向 2024 年 bioRxiv 预印本 PMID 38645222。这些关联尚需逐条阅读和领域人员判断，自动检查未覆盖完整的更正、撤稿与版本链。

最后纳入的 [PMC11269463](https://europepmc.org/articles/PMC11269463) 是 2024 年《Bioinformatics》的 `perox-per-cell` 过氧化物酶体图像定量方法论文，PMID 39001800，DOI `10.1093/bioinformatics/btae442`。其题名、正文和方法段与目标主题直接相关，官方 XML 年份为 2024，许可为 CC BY 4.0；仍未由独立领域专家判断其方法与结论适用范围。

首批 14 篇按 2021/2022/2023/2024 年分布为 3/3/4/4 篇；补采再给 2024 年增加 1 篇。两批 15 篇均为父库没有的新论文，没有摘要升级。连同历史批次的 33 篇，原定的 48 个主题×年份组合现均有至少一篇符合本次自动来源和许可条件的全文。**每组一篇只表示目标格子被填充，不表示该主题的文献覆盖充分。**

首批有 105 条拒收尝试记录，定向补采有 13 条；这些是候选尝试次数，同一论文可能跨组重复，不能解释为 118 篇不同的无效论文。主要原因是题名、摘要或类型初筛不符，官方年份不同，许可不属于允许范围或许可链接不唯一，以及下载失败。未为填满配额而放宽条件。`curation_decisions.json` 两批均没有人工排除项，自动来源、许可和主题初筛不构成领域专家审核。

所有向量仍为 4,096 维 `Qwen/Qwen3-Embedding-8B`，指纹 `40d76b3e9cfbecb7d10f0b7a`，分块数与向量数一致。v24、v25 各自的 `index_verification.json` 对父库文档、筛选 JSON、原始 XML、标识、许可、上传原件、正文和向量完成只读核查，错误列表为空。对应的 `api_verification.json` 在 SQLite 临时副本核对了论文目录和题名 BM25 召回。题名检索是功能冒烟检查，**没有得到独立检索质量或科研问答正确率**。

## 作者字段修复

入库后检查发现，旧解析器只识别 `<contrib contrib-type="author">`，遗漏 `<contrib-group content-type="author">` 下的作者。该问题使历史批次 33 篇和首批 14 篇的作者字段为空；原始 XML 含有作者，正文、标识及许可不受影响。修正解析器并增加包含作者组与编辑组的回归测试后，补采论文在入库前根据原始 XML 补齐 9 位作者，变更前后 SHA-256 记录在 `author_repair_report.json`。

为保护已验收的 v25，使用独立 v26 从它复制，再按原始 XML 补齐前述 47 篇的作者字段。`AUTHOR_ENRICHMENT.json` 逐篇保存 PMCID、原文摘要和作者；`AUTHOR_VERIFICATION.json` 确认只改变这 47 条作者元数据，父库正文、其他字段、上传原件、分块和向量保持一致。最终 89 篇全文的作者字段均非空。论文目录 API 在临时副本逐篇核对了这 47 个作者列表，报告为 `AUTHOR_API_VERIFICATION.json`。

## 本机验收与运行

v26 数据库 SHA-256 为 `4aef7ac0f19f9fbe890b8894882805121be55b0f59e92938e0a01dbd55a9498b`。`DOCTOR_VERIFICATION.json` 在临时副本确认索引指纹兼容，未调用在线模型。浏览器对 v26 的临时副本完成 10 项工作台交互检查，页面和控制台错误均为 0；报告及截图在 `output/authors_20261105_browser/`。全量主线自动化测试 143 项通过，相关 Ruff 检查通过。`start-expanded.bat` 只在当前进程指向 v26，保留 CRLF，不改写 `.env` 或旧启动入口。

```powershell
.\start-expanded.bat
# 或显式选择独立库：
.\.venv\Scripts\python.exe -m biokb --data-dir data/biokb-v26-authors-20261105 serve
```

重新核对时，可依次执行 `scripts.verify_pubmed_snapshot`、`scripts.verify_expanded_index` 与 `scripts.verify_expanded_api`，分别以两个采集批次及对应的 v24、v25 为参数；v26 的作者差异以 `AUTHOR_VERIFICATION.json` 和 `AUTHOR_API_VERIFICATION.json` 核对。数据库与原始 XML 均不进入源码包。
