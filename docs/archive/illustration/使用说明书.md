# 科研配图 AI 系统（Sci-Illust）使用说明书

面向同事的快速上手说明。本系统在**本机运行**，生成可编辑的科研 SVG 配图，无需服务器。

---

## 1. 这是什么

输入一段科研图注需求（例如机制图、信号通路、细胞示意），系统会：

1. 从知识库识别关键元素与关系  
2. 规划构图并生成 **可编辑 SVG**  
3. 在绘图台画布上修订、对齐、导出  

主界面模块：

| 模块 | 用途 |
|------|------|
| **绘图台** | 写需求 → 生成 SVG → 拖拽修订 → 下载 |
| 概览 | 系统状态与数据概览 |
| 文献与术语 | 文本知识库相关 |
| 图元素材库 | 浏览/检索图元 |
| 系统设置 | Ollama 等本地配置 |

---

## 2. 环境要求

| 项目 | 要求 |
|------|------|
| 系统 | Windows 10/11 |
| Python | 3.10+（推荐 3.11 / 3.12） |
| 浏览器 | **Edge 或 Chrome**（桌面窗口模式需要） |
| 网络 | 仅安装依赖、拉取模型时需要；日常可离线使用 |
| 可选 | [Ollama](https://ollama.com)（本地大模型，出图质量更好） |

## 3. 第一次安装（约 5–10 分钟）

### 3.1 拿到源码

解压同事发来的压缩包（或使用仓库目录），得到文件夹，例如：

```text
keyanhuitu\
  start.bat
  gui.py
  requirements.txt
  sci-illust-system\
  使用说明书.md
  ...
```

### 3.2 安装 Python 依赖

在资源管理器中进入该文件夹，地址栏输入 `cmd` 回车，执行：

```bat
pip install -r requirements.txt
```

### 3.3（推荐）安装 Ollama 并拉取模型

1. 打开 https://ollama.com 安装 Ollama  
2. 新开一个终端执行：

```bat
ollama serve
ollama pull qwen2.5:3b
```

> 没有 Ollama 也能启动系统：会走知识库/规则回退，功能可用，但智能分析效果较弱。

### 3.4（可选）配置图元库路径

若本机有 Bioicons 或元素映射数据，可复制 `.env.example` 为 `.env`，按需修改：

```text
SCI_FOCUS_DOMAIN=biology
OLLAMA_DEFAULT_MODEL=qwen2.5:3b
# SCI_OUTPUT_KB=你的元素映射目录
# BIOICONS_ROOT=你的 Bioicons 目录
```

不配置也能启动；图元会更多使用内置形状回退。

## 4. 日常启动

在项目根目录双击或命令行运行：

```bat
start.bat
```

默认会打开**桌面窗口**（Edge/Chrome 的 App 模式）。

其他方式：

| 命令 | 说明 |
|------|------|
| `start.bat` / `start.bat gui` | 桌面窗口（推荐） |
| `start.bat web` | 仅启动服务，浏览器打开 http://127.0.0.1:5000 |
| `python gui.py` | 与 gui 模式相同 |

启动后请保持窗口开着；关闭窗口即结束本次使用。

## 5. 怎么出一张图（绘图台）

1. 左侧选择 **文本出图**  
2. 在需求框写清图意，例如：

   > EGF 配体结合 EGFR 受体，激活 RAS 激酶，形成细胞膜信号通路示意图  

3. 可按需选择布局、风格、模型  
4. 点击 **生成配图**  
5. 右侧画布出现 SVG 后：
   - **选择**：点击高亮组件  
   - **移动**：拖动调整位置  
   - **平移**：拖动画布查看  
   - 属性面板：对齐、颜色等  
   - **撤销 / 重做**：Ctrl+Z / Ctrl+Y  
6. 满意后下载 SVG，可用 Illustrator、Inkscape、PowerPoint 等继续编辑  

### 其他出图方式

- **草图出图**：上传 SVG/PNG/JPG 草图 + 文字说明，系统结合草图生成  
- **基于上次结果修改**：在「图片描述」写修改要求（如「把 RAS 改成红色」），再生成  

### 示例提示词

```text
画一张细胞截面：细胞膜上有 EGFR，胞外有 EGF，胞质中有 RAS 和 MAPK，用箭头表示激活关系
```

```text
实验流程图：样本制备 → 细胞培养 → 免疫荧光染色 → 成像分析
```

## 6. 输出说明

- 默认渲染模式为 **Scene（场景图）**：矢量图元、分层结构，便于后期改色/改标签  
- 导出格式：**SVG**（推荐保留，不要只截图）  
- 本地数据库：`sci-illust-system\web_app\data\knowledge.db`（首次运行自动创建，勿提交到 Git）

## 7. 常见问题

**Q：双击 start.bat 闪退？**  
A：多半是没装 Python 或没进对目录。用 `cmd` 进入项目根目录再运行 `start.bat`，看报错信息。确认 `python --version` 可用。

**Q：提示找不到 Edge/Chrome？**  
A：安装 Edge 或 Chrome；或用 `start.bat web`，再手动打开 http://127.0.0.1:5000 。

**Q：生成很慢或分析很弱？**  
A：确认 Ollama 在跑（`ollama list`），模型已拉取；在「系统设置」里检查模型名是否与本机一致。

**Q：图元太抽象、不像专业图标？**  
A：配置 `BIOICONS_ROOT` / `SCI_OUTPUT_KB` 指向本机图元库后效果更好；否则会用几何形状回退。

**Q：端口被占用？**  
A：`start.bat web` 默认用 5000；gui 模式会自动选空闲端口。关掉旧的 Python/本系统窗口后再开。

**Q：杀毒软件拦截？**  
A：首次运行 Python / 本地服务可能被拦截，加入信任即可。本系统不访问外网数据库。

## 8. 给同事打包源码（维护者）

在项目根目录运行：

```bat
pack.bat
```

会生成 **`SciIllust-source.zip`**（一个压缩包即可转发）。  
解压后按本文第 3、4 节安装与启动。

> 不要同时保留多套拷贝目录；以解压出的这一份文件夹为准。

如需自行打 exe（体积较大，依赖本机 Python 环境）：

```bat
build.bat
```

产物在 `dist\`（若已清理则需重新打包）。

## 10. 使用注意

- 本系统为**本地工具**：数据与生成结果默认留在本机  
- 生成图请人工核对生物学/机制表述，再用于论文或汇报  
- 导出 SVG 后可用专业矢量软件精修至期刊规范  

如有安装或启动问题，把终端完整报错截图发给维护同事即可。
