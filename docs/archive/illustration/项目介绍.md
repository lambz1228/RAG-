# 科研配图 AI 系统（Sci-Illust）项目介绍

> 汇报材料 · 可与源码包一并提交  
> 项目目录：`keyanhuitu`  
> 运行形态：本地 Windows 桌面 / 浏览器 · 无需云端服务器

---

## 一、项目背景与目标

科研论文与课题汇报高度依赖**机制图、通路图、实验流程图**。现有做法多为：

- 在 PowerPoint / Illustrator 中手工拼图，耗时长、难统一风格；
- 通用文生图（位图）难以二次编辑，也不符合期刊对矢量、可改标签的要求。

本项目目标是构建一套**本地可运行的科研配图辅助系统**：用户用自然语言描述图意，系统自动规划元素与关系，输出**可编辑 SVG**，并支持在画布上继续修订与导出。

**设计原则：**

| 原则 | 说明 |
|------|------|
| 本地优先 | 数据与推理留在本机，保护科研材料与隐私 |
| 矢量可编辑 | 默认输出 SVG，便于后续精修与投稿 |
| 知识驱动 | 术语库 / 图元库 / 元素映射参与构图，而非纯随机生成 |
| 人机协同 | AI 出初稿，人工在绘图台完成最终调整 |

---

## 二、系统定位

**Sci-Illust（科研配图 AI 系统）** = 知识库检索 + 本地大模型编排 + 场景化 SVG 渲染 + Web/桌面工作台。

典型使用场景：

1. 根据图注文字生成信号通路 / 细胞截面示意图；  
2. 结合草图说明做结构化重绘；  
3. 对上一版结果做增量修改（改色、增删关系等）；  
4. 浏览术语与图元素材，辅助选题与构图。

| 桌面入口 | `gui.py` / `start.bat` | 一键启动本地服务与独立窗口 |

## 四、关键技术要点

### 1. 场景化矢量渲染（SceneRenderer）

- 默认 `mode: scene`，面向机制图 / 细胞截面，而非仪表盘式「卡片拼贴」。  
- 外部图元以 **inline SVG** 嵌入，避免 base64 位图化，便于 Illustrator 等工具改色、拆层。  
- 输出分层：`background` → `cell-context` → `connections` → `elements` → `labels`。  
- 支持期刊风格预设（如 Nature / Science / Cell 配色思路）。

### 2. 元素映射与图元召回

- 文本侧术语与图片侧素材通过**规范元素 ID**对接（如线粒体、膜受体），避免文献与图片盲目两两配对。  
- 优先召回可 inline 的轻量 SVG；过大或伪 SVG（实为 PNG）会校验并回退。

### 3. 连接布局与可编辑性

- 正交折线 / 全局路由，减少箭头穿节点与交叉。  
- 画布支持选择、移动、对齐、撤销重做，导出后仍可二次编辑。

### 4. 本地大模型增强（可选）

- 通过 Ollama 调用中文友好小模型（如 `qwen2.5:3b`）做需求理解与结构化分析。  
- 无模型时系统仍可启动，走知识库与规则回退，保证演示与离线可用性。

### 5. 质量评估

| 维度 | 权重 | 含义 |
|------|:----:|------|
| 元素完整性 | 40% | 需求中的关键元素是否覆盖 |
| 布局合理性 | 35% | 重叠、对齐、间距 |
| 可编辑性 | 25% | 分组、标注、颜色结构是否利于后期修改 |

## 五、功能与界面

| 功能页 | 说明 |
|--------|------|
| **绘图台** | 文本出图 / 草图出图 / 基于上次结果修改；画布修订与导出 |
| 概览 | 系统与数据状态总览 |
| 文献与术语 | 文本知识相关管理与检索入口 |
| 图元素材库 | 图元浏览与建议 |
| 系统设置 | Ollama 等本地配置 |

**启动方式（Windows）：**

```bat
start.bat          :: 桌面窗口（推荐演示）
start.bat web      :: 浏览器访问 http://127.0.0.1:5000
```

依赖安装：`pip install -r requirements.txt`  
详细操作见同目录《使用说明书.md》。

## 六、技术栈与工程形态

| 类别 | 选型 |
|------|------|
| 语言 | Python 3.10+ |
| Web | Flask + Waitress |
| 桌面壳 | 本机 Flask + Edge/Chrome `--app` 窗口 |

## 七、演示建议（汇报可用）

1. 运行 `start.bat`，打开绘图台。  
2. 输入示例需求，例如：

   > EGF 配体结合 EGFR 受体，激活 RAS 激酶，形成细胞膜信号通路示意图  

3. 展示生成 SVG 的分层结构与画布拖拽修订。  
4. 导出 SVG，用 Illustrator / Inkscape 打开，说明「可编辑矢量」相对位图的优势。  
5. （可选）关闭 Ollama 再生成一次，说明回退策略与本地可用性。  

示例产出可参考：`sci-illust-system/examples/scene_hq.svg`。

## 九、局限与后续计划

| 现状局限 | 后续可加强方向 |
|----------|----------------|
| 图元库依赖本机路径配置，未配置时几何回退较多 | 内置精简公开图元子集，零配置也可出专业图标 |
| 小模型对复杂通路理解有限 | 支持更大本地模型或结构化模板库 |
| 期刊级排版仍需人工精修 | 增加投稿尺寸模板、字号/线宽规范检查 |
| Critic / 评估偏规则 | 引入更多领域校验与用户反馈闭环 |
