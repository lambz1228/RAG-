1. 正确性：统一实体识别，保留激活、抑制、结合等关系语义；未明确关系不自动作为确定机制。复核已有失败测试，补充中英文混排、分支、歧义回归。
2. 图形闭环：扩展现有 workflow 保存稳定 ID、位置、样式、来源；实现受约束修改、手工编辑同步、项目版本保存与重新打开。修改不涉及的节点保持稳定。
3. 知识证据：绘图接入可选择的检索策略，返回带出处的证据；GraphRAG 失败有明确状态与超时；证据补充和用户需求分别保存。
4. 布局与评估：支持固定位置和局部变更，输出遮挡、越界等诊断；以独立参考实体和关系进行评测，提供开发/评测分离的样例与可复现实验脚本。演示样例不是专家核验数据，联网模型实验不能用模拟结果代替。
5. 工程交付：集中配置、异步进度、可移植测试、页面职责拆分和文档更新；完成核心、接口、前端与回归验证。
