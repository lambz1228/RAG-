# 真实语义版运行与验收

2026年11月16日，把134份扩充资料的8,083个片段编码为真实多语言语义向量，增加中英生物术语补充，并完成开发检索对照与本地生成验证。模型文件、版本和实际结果见[本轮记录](../research/semantic-dev-v1/README.md)。

## 运行组成

- 向量模型：官方intfloat/multilingual-e5-small的固定ONNX INT8文件，384维。文献使用`passage: `前缀，问题使用`query: `前缀；注意力掩码平均池化后进行L2归一化。
- 原文、题目和引用位置不因模型更换而改写；编码最多512词元，原文仍完整保留。
- 可选术语补充把中文生物名词附加为英文检索词，保留原问题，不添加答案、指定论文或题号，也不改变BM25分词。术语版本、字典摘要及模型摘要分别登记。
- 本地生成使用Qwen2.5-3B-Instruct Q4_K_M，经llama.cpp兼容接口调用。模型适用上游Qwen RESEARCH LICENSE，本轮用于毕业设计非商业研究，不随仓库分发。

模型未配置时仍采用原有离线基线。启用本地模型后，缺依赖、清单不匹配或权重摘要不符会明确报错，不将失败的索引改称语义模型。

## 建立真实索引

先按[扩充语料说明](../research/cell-biology-expanded-v2/README.md)取得并合并134份资料，再执行：

```bash
python -m pip install -e ".[local-embedding]"
python scripts/download_e5_model.py --output data/models/multilingual-e5-small
python -m biokb create-revision data/cell-biology-v2/database data/cell-biology-v2-semantic
python -m biokb --env-file config/local-semantic.env.example --data-dir data/cell-biology-v2-semantic reindex
python -m biokb --env-file config/local-semantic.env.example --data-dir data/cell-biology-v2-semantic doctor
```

下载器只访问固定官方模型仓库与修订，核对上游LFS SHA-256或Git对象摘要，再生成本机`MODEL_MANIFEST.json`。输出目录应尚不存在；权重放在被Git忽略的`data/`目录。原库、上传文献与原始来源随独立版本保留。

本次机器为Linux、CPU配额2核、内存8GiB，单次索引约305秒；该耗时有并发开发活动影响，不作为模型速度优劣结论或其他机器的运行保证。

## 启动本地生成

从[固定修订的模型文件](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/7dabda4d13d513e3e842b20f0d435c732f172cbe/qwen2.5-3b-instruct-q4_k_m.gguf)取得权重，保留[上游许可](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/blob/7dabda4d13d513e3e842b20f0d435c732f172cbe/LICENSE)。文件大小为2,104,932,768字节，SHA-256为：

```text
626b4a6678b86442240e33df819e00132d3ba7dddfe1cdc4fbb18e0a9615c62d
```

使用已安装的llama.cpp启动，模型路径按实际位置填写：

```bash
llama-server --model data/models/qwen2.5-3b-instruct-q4_k_m.gguf --host 127.0.0.1 --port 18082 --alias biokb-qwen2.5-3b --ctx-size 8192 --parallel 1 --threads 2 --threads-batch 2
```

在另一终端启动工作台：

```bash
python -m biokb --env-file config/local-semantic.env.example --data-dir data/cell-biology-v2-semantic serve
```

该配置默认开启本轮术语补充。也可使用已有Ollama或兼容生成服务，按实际接口修改独立配置文件；模型、提示、上下文预算或输出协议变化后，应作为新实验配置记录。示例配置不会覆盖现有`.env`或系统环境变量，已有环境变量优先。
