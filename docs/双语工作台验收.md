# BioKB 双语工作台验收

日期：2026-11-04。对应需求：将 BioKB 改为 Trilium 风格的工作台，并支持中英文切换。

本文记录 2.1 当时的界面验收。2.2 已按后续需求移除最左侧独立图标栏，并增加科研文献页；当前状态见[科研证据整改验收](科研证据整改验收.md)。

## 实现范围

继续沿用 Flask、SQLite 和原生 JavaScript，在现有 RAG 功能上接入紧凑多栏布局。左侧为工具栏、功能导航和文献树；中间为可关闭标签页和业务内容；右侧为当前页面目录。窄屏隐藏右侧目录，手机使用导航抽屉。

- 文献树按论文摘要、论文全文、知识条目、待补充条目分组，按需读取，每批 40 条；支持加载更多、按标题或文件名搜索以及直接打开原文。
- 标签页支持切换、关闭、方向键和 Home/End；当前页面会话内重新打开标签时保留输入和结果。阅读标签展示当前打开的文献。
- 中文和 English 即时切换，浏览器保存语言选择。导航、表单、状态、按钮、日期、证据定位信息与常见业务错误随语言切换。
- 文献标题、原文、用户问题和模型回答保持原始内容；切换语言不调用 API、不重新生成答案。文献详情弹窗与主界面的语言选择同步。
- 左右面板可折叠，Ctrl / ⌘ + K 打开文献搜索；手机导航支持遮罩和 Escape 关闭、选定功能后自动收起。

前端职责分为 `shell.js`（布局、标签和文献树）、`i18n.js`（翻译和语言状态）、`messages.js`（英文词表），继续由 `documents.js`、`research.js`、`main.js` 处理原有业务。新增静态资源已纳入 wheel；工作台自动化验收已加入 CI 配置。

## 中断点与修复

前轮界面改造已写入文件，验收期间先后发现手机导航未展开便点击、切换语言覆盖最近入库列表、文献树分页回调失效的问题。当前代码及验收脚本已修复，完整流程复测通过。

最后的中断发生在真实库副本截图后的清理阶段：`sqlite3.Connection` 的上下文管理负责事务提交或回滚，并不关闭连接；连接仍被引用时，Windows 拒绝删除临时数据库。本轮先复现 `WinError 32`，再在截图复制和实验版本复制中使用 `contextlib.closing` 显式释放两端连接。正常备份和模拟中断均有回归测试，源库摘要保持不变。未用忽略清理错误的方式掩盖故障。

截图复核同时修正了手机端“导入文献”按钮被压缩换行的问题。

## 运行与复现

本轮源码包为 `output/distributions/BioKB-source-2.1.0-20261104-trilium.zip`；安装包为 `output/ui_trilium_20261104/wheel_final/biology_rag_kb-2.1.0-py3-none-any.whl`。旧版产物保留；本轮包沿用 2.1.0 版本号，以路径区分界面更新。源码包包含主线代码、测试和文档，不含 `.env`、知识库、原文或本机问答输出。交付摘要及核验结果见证据目录中的 `package_report.json`、`delivery_manifest.json`。

双击项目根目录的 `start.bat`，或运行：

```powershell
.\.venv\Scripts\python.exe app.py
```

默认地址为 `http://127.0.0.1:5000`。若已有旧进程，先重启应用；浏览器必要时用 Ctrl + F5 更新静态资源。右上角的语言选择可即时切换中文和 English。

安装浏览器测试依赖和 Chromium 后，可独立运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/verify_browser.py --output output/browser_check
.\.venv\Scripts\python.exe scripts/verify_workspace.py --output output/workspace_check
# 可选：仅读取正式库，并在临时副本中截图
.\.venv\Scripts\python.exe scripts/verify_workspace.py --output output/workspace_snapshot --snapshot-data data/biokb-v21-semantic
```

## 适用边界

本次验收确认界面和工程行为，不重新评估真实模型的生物学回答质量。浏览器业务验证使用临时测试语料和离线模型，重排序使用受控夹具；真实语义库仅用于只读副本截图。既有模型实验与待人工复核状态见 [2.1 优化验收](2.1优化验收.md)，没有填写或替代专家评分。

语言选择可在刷新后恢复；尚未提交的输入、打开的标签与当前阅读文献不保证跨刷新恢复。页面按单个阅读标签展示当前文献，不提供 Trilium 的笔记编辑、知识图谱或任意嵌套笔记功能。CI 配置已更新，本工作区没有远端 GitHub Actions 执行记录。
