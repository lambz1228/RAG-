## 1. 评估目标

1. 回答准确性：独立题集上的事实正确率、证据支持率、完整性。
2. 幻觉抑制：无支持断言数、拒答恰当率（有证据但拒答、无证据却作答两类错误）。
3. 检索有效性：原子证据在片段级和论文级的召回率。
4. 系统有效性：在冻结题集上的一次性正式运行结果，支撑论文"验证系统有效性"结论。

## 2. 题库构成（v1 定稿配额）

- 正式评测集 100 题，开发集另设（开发集不与正式集共用论文）。

| 题型 | 数量 | 说明 |
| --- | --- | --- |
| 方法条件 | ≥25 | 细胞系、培养基、配比、时长、浓度等单点方法事实 |
| 机制/结论 | ≥20 | 原文明确支持的机制与结论判断 |
| 跨论文比较或冲突 | ≥20 | 至少两篇论文间的异同、矛盾与出处并列 |
| 无答案 | ≥20 | 库内无充分证据，应拒答 |
| 版本/时效 | ≥15 | 涉及更正、撤稿或版本差异的问题 |

冻结说明：v1-machine 已覆盖 方法条件 30、机制/结论 25、无答案 20 达标；跨论文比较 6、版本/时效 1 因数据限制（同刊论文对耗尽、18 条版本关系中仅 1 条 DOI 在库内正文）暂缺，缺口由人工出题补齐后冻结 v1-manual 增补集，两者合并构成正式评测集。

## 3. 出题与标注规则（v1 定稿）

1. 出题可由领域评审者独立编写，或由已配置的真实模型生成草稿后经人工复核（v1 采用后者：v1-machine 即机器草稿）。机器草稿不得未经复核直接计入正式评测结论。
2. 每题给出原子答案要点（可拆分的最小论断），并标注支持/反驳原文的精确字符区间、论文版本、PMID/PMCID/DOI、原文文件 SHA-256；字符区间与 SHA-256 由程序在库内正文定位校验（questionbank validate），人工复核负责事实正确性。
3. 至少 30% 题目双人独立复核，分歧由裁决人裁决并留痕（抽检表：`questionbank/机器标注抽检表.csv`，25 题，种子 20261113）。
4. 无答案题须写明"库内不应有证据"的检索依据；v1-machine 已附 hybrid_rerank top1 检索最高分作为机器依据，仍须人工确认。
5. 正式集完成即冻结，登记整体 SHA-256，之后只能新增实验版本；复核结论回填后冻结新版本（human_review_status 置为已复核），不追改 v1-machine。
6. 出题模板：`output/research_quality_v26_20261105/review_templates/独立证据题集_空白模板.csv`；机器草稿：`questionbank/machine_annotated.csv`。

## 4. 评分维度

| 维度 | 评分 | 定义 |
| --- | --- | --- |
| 事实正确性 | 0/1/2 | 原子要点与原文的一致程度（2 全对） |
| 证据支持 | 0/1/2 | 引用的原文区间是否支撑论断 |
| 完整性 | 0/1/2 | 原子要点的覆盖程度 |
| 拒答恰当性 | 恰当/漏答/误答 | 无证据题是否拒答、有证据题是否拒答 |
| 无支持断言数 | 整数 | 回答中无任何证据区间支撑的论断条数（幻觉度量） |

评分表：`output/research_quality_v26_20261105/review_templates/全文开发题_人工复核空白.csv` 的字段结构沿用；评分者盲评，评分前不得看其他评审者的分数。

## 5. 放行门槛（建议值，待导师确认）

- 事实正确性与证据支持同时得满分的回答占比 ≥ 90%。
- 关键无支持断言（影响结论的）为 0。
- 无答案题拒答率 ≥ 90%；有证据题错误拒答率 ≤ 10%。
- 冲突题能并列出处并说明分歧的比例 ≥ 90%。
- 原子证据片段级 Recall@10 ≥ 0.95（机器指标，仅作辅助，不替代人工评分）。

## 6. 运行与冻结规则

1. 正式运行只在未参与开发、调参、出题评审的题集上进行一次。
2. 运行前登记：题集 SHA-256、索引版本与数据库 SHA-256、embedding/重排序/生成模型指纹、prompt 版本。
3. 正式结果不与其他口径混合：开发题、旧 69 题、定向回归均标注为诊断，不得换算为正式成绩。
4. 任何参数或题集变更后需重新运行，新建实验版本。
5. 人工复核字段必须由真实评审者填写，模型格式通过率不作为学术正确率。
